Accès API

PlanèteCube Uploader API

v1.0.0/api/v1

Accès programmatique pour les uploaders dont la demande d’accès API a été approuvée.

Authentification

Envoyez votre clé via Authorization: Bearer <clé> ou X-API-Key: <clé>. Les clés ressemblent à lxu_…. Le secret en clair n’est affiché qu’une fois à la création — seul un hash est stocké, donc une clé perdue doit être renouvelée.

Scopes

Chaque clé porte une liste explicite de scopes ; une route la rejette avec 403 insufficient_scope si le scope requis est absent.

Limites de débit

120 requêtes/min par clé, portées à 300/min pour les uploaders de confiance. Les clés du staff sont illimitées. Un dépassement renvoie un 429 avec un en-tête Retry-After.

Liste d’IP autorisées

Une clé peut épingler une liste d’IP appelantes exactes. Les entrées sont comparées littéralement — les plages CIDR ne sont pas prises en charge.

Démarrage rapide

Chaque appel nécessite une clé. Commencez par celui-ci : il renvoie votre identité et les scopes de votre clé, et ne demande aucun scope.

curl -H "Authorization: Bearer lxu_your_key_here" \
  https://api.planetecube.fr/api/v1/me

Essayer

Choisissez une de vos clés et collez son secret pour appeler les endpoints de lecture directement depuis cette page. Nous ne stockons qu'un hash de vos clés : le secret ne peut donc pas être pré-rempli. Il reste dans cet onglet et disparaît à sa fermeture.

Vous n'avez pas encore de clé API. En créer une

Scopes

  • links:readLire les liens et leurs fichiers NFO.
  • links:writeCréer, modifier et supprimer vos liens et NFO.
  • media:readLire le catalogue de médias.
  • media:writeCréer et modifier médias, saisons et épisodes.
  • requests:readLire la file des demandes de médias.
  • requests:fulfilSatisfaire les demandes et changer leur statut.
  • assets:writeProposer des affiches et autres assets.
  • tmdb:readRechercher sur TMDB via l'API.
  • stats:readLire vos propres statistiques d'uploader.

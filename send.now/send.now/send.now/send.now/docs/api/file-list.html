GET

https://send.now/api/file/list?key=1ltghrilhllgrx2b2&page=2&per_page=20&fld_id=15&public=1&created=2024-08-21%2005%3A07%3A10&name=My documents

Parameters Description Example Format Required
key API-Key 1ltghrilhllgrx2b2 STRING yes
page page number 2 Number no
per_page Number of files per page 20 Number no
fld_id Folder id 15 Number no
public show public or private files 1 or 0 Number no
created Show only files uploaded after timestamp. 2024-08-21 05:07:10 String no

cURL example


curl --include \
'https://send.now/api/file/list?key=1l5ftrilhllgwx2bo&page=2&per_page=20&fld_id=15&public=1&created=2024-08-21%2005%3A07%3A10&name=My documents'
